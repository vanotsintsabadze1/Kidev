Vendored Lucide icons, version 0.468.0
Source: https://github.com/lucide-icons/lucide/tree/0.468.0/icons
License: https://github.com/lucide-icons/lucide/blob/0.468.0/LICENSE

lucide.svg contains unchanged child geometry from these official SVG files;
each symbol ID is the upstream filename without .svg:
layout-dashboard.svg (Overview)
list-checks.svg (Jobs)
repeat.svg (Recurring)
calendar-clock.svg (Scheduled)
server.svg (Workers)
circle-x.svg (Failed)
chart-no-axes-combined.svg (Metrics)
settings.svg (Settings)
refresh-cw.svg (Refresh)
menu.svg (Menu)
log-out.svg (Sign out)
sun-moon.svg (Theme)

Only the outer SVG wrappers were replaced by symbols. The consuming SVG
retains the upstream 24x24 viewBox, fill="none", stroke="currentColor",
stroke-width="2", and round caps/joins, displayed at 16x16 CSS pixels.
